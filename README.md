# Leaving NYC

Live traffic on the ways out of New York City — the site behind [@leavingnyctonight](https://instagram.com/leavingnyctonight).

Static page, no backend: traffic comes straight from NYC DOT's Real-Time Traffic Speeds feed on NYC Open Data (dataset `i4gi-tjb9`), which also keeps the day's history. Basemap © CARTO / OpenStreetMap, drawn with MapLibre.
